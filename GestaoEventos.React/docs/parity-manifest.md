# GestaoEventos React Parity Manifest

Este arquivo e o ledger de release do app React. Uma rota ou fluxo so conta para a migracao quando sua linha estiver `verified` e a evidencia de teste estiver registrada.

> Auditoria visual canonica de todas as rotas: `docs/ui-parity-audit-20260907.md`.

## Status Values

| Status | Meaning |
| --- | --- |
| `not-started` | Item planejado, ainda sem implementacao React. |
| `in-progress` | Item em desenvolvimento ou aguardando evidencia completa. |
| `blocked` | Item impedido por decisao, dependencia ou contrato ausente. |
| `verified` | Item implementado, testado e rastreavel contra Angular/API. |
| `deferred` | Item conscientemente fora do release atual, com gap registrado. |

## Required Schema

| Field | Required evidence |
| --- | --- |
| React route/flow | Rota Expo Router ou fluxo transversal React. |
| Angular route/component | Rota e componente Angular usados como baseline produtivo, ou `N/A` quando nao existir equivalente. |
| Angular service/source | Service/fonte Angular que demonstra contrato ou comportamento, ou `N/A`. |
| Backend endpoint/class | Endpoint `/api/...` e classe backend real, ou `N/A`. |
| Context scope | Escopo ativo exigido: publico, usuario, estrutura, grupo, evento ou global. |
| Permission checks | Permissoes dinamicas/owner bypass exigidos, ou `none`. |
| Analytics events | Eventos `ge_event` esperados: `visualization`, `entrance`, `simulation`, `confirmation` conforme o fluxo. |
| Tests | Smoke/E2E/regression/typecheck/lint que comprovam paridade. |
| Status | Um dos valores permitidos neste documento. |
| Gaps | Diferencas conhecidas, decisoes pendentes ou justificativa de `N/A`. |
